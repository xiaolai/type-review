Privacy Policy

TYPE for macOS and type.review · Last updated 8 September 2026

TYPE collects nothing. There is no account, no sign-in, and no server. Everything the app records about your typing stays on your own machine, in a file you can open, move, or delete.

What the app stores

One JSON file in the app's own container, holding your practice history: words per minute, accuracy, and per-key timings for each run, plus your settings. Nothing in it identifies you. You can reveal it in Finder from Settings → Data, export it, import it, or delete it — deleting it erases every statistic the app has.

What the app sends

Nothing. TYPE makes no network requests of any kind. It contains no analytics, no crash reporting, and no advertising. This is a property of the build rather than a promise: the application links no networking framework, and its source contains no HTTP client. The only address anywhere in the app is the link to this website, which opens in your browser when you click it.

The optional keyboard sound

TYPE can play a keyboard sound for keys pressed in other applications, so a quiet keyboard can be given the sound of a mechanical one. This is off by default. Switching it on asks macOS for Input Monitoring permission, and the app never asks on launch.

While it is on, four things constrain what the app can see:

  • It reads keyCode only — which physical key moved. It cannot tell an a from a q, or a password from a sentence.
  • While any password manager is frontmost, the event tap is uninstalled rather than muted. The events are not delivered to the app at all.
  • Every secure text field in macOS silences it, including fields in applications nobody thought to enumerate.
  • Nothing is stored, buffered, or transmitted. The only output is one audio buffer per keystroke.

Speaking words aloud

TYPE can read a word aloud once you have typed it correctly. This uses macOS's built-in speech synthesis, on your own device, and involves no network. It is off by default, and it only ever speaks words from the passage on screen.

Children

TYPE is suitable for children learning to read and type. It collects no data from anyone, of any age, and contains no advertising, no in-app purchases, and no user-generated content.

This website

type.review runs the same typing practice in a browser. Your statistics are kept in your browser's local storage and are never uploaded. The site has no accounts, no cookies for tracking, and no advertising.

The site is served from Cloudflare Pages. It carries no analytics of any kind — no page-view counting, no beacon, no third-party script. Cloudflare handles ordinary request logs as part of delivering the pages, as any web host does, and nothing else about your visit is recorded anywhere.

Third parties

The app shares data with nobody, because it holds nothing to share and sends nothing anywhere. The website's only third party is the host described above.
